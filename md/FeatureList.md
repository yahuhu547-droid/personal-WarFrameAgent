# Warframe 交易助手 — 功能清单

> 一个基于多模型协作的 Warframe 个人交易 Agent，通过飞书机器人和 Web 界面为玩家提供实时市场数据、智能交易决策和主动提醒服务。

---

## 核心功能

### 1. 实时价格查询
- 输入物品中文名/英文名/别名，自动查询 warframe.market 实时数据
- 返回最低卖价、最高收价、价差、私聊命令
- 支持多物品对比（如"充沛 vs 复仇者"），生成对比表格
- 支持套装查询（整套 vs 拆件价格对比）

### 2. 套装补齐计算
- 输入已有部件，计算补齐剩余部件需要多少白金
- 自动对比整套买 vs 拆件买的成本差异

### 3. Mod 翻转分析
- 扫描所有 Mod，找出低级买、满级卖能赚钱的 Mod
- 按每千内融利润排序，包含买入价、卖出价、利润、成交量
- 支持赋能（Arcane）翻转分析

### 4. Prime 套装利润分析
- 对比套装 vs 拆件的价格差异
- 推荐"买部件→卖套装"或"买套装→卖部件"策略
- 显示 48 小时成交量

### 5. 投资顾问
- 输入预算和目标 ROI，推荐投资机会
- 按 ROI 排序，过滤低成交量物品
- 标注风险等级

### 6. 价格趋势预测
- 基于历史价格数据的线性回归预测
- 输出趋势方向、置信度、预测价格区间
- 支持事件修正（Baro 来访、Vault 等）

### 7. 交易策略模板
- 预设策略：低风险赋能翻转、中风险 Prime 拆件、高风险 Vault 投机
- 一键扫描策略下的交易机会

## 游戏数据功能

### 8. 遗物掉落查询
- 查询某个 Prime 部件从哪些遗物掉落（含掉落率）
- 查询某个遗物的全部掉落物
- 自动关联当前活跃裂缝，标注"现在可以刷"

### 9. 游戏活动查询
- 当前活跃的虚空裂缝（支持等级/任务/地点/模式过滤）
- Baro 虚空商人来访状态
- 入侵、警报、虚空风暴等事件

### 10. Baro 购买推荐
- Baro 来访时自动分析库存
- 按"值得买 / 可考虑 / 不推荐"分类
- 对比 Baro 价格与市场价

---

## 自动化功能

### 11. 价格监控与提醒
- 关注物品列表，定时扫描价格
- 设置价格阈值提醒（高于/低于目标价）
- 价格突变预警（3 小时内涨跌超过 20%）

### 12. 裂缝订阅推送
- 订阅特定条件的裂缝（等级 + 任务 + 地点 + 模式）
- 匹配裂缝出现时自动推送通知

### 13. 交易记录自动追踪
- 识别"我买了充沛 80p"等自然语言，自动记录交易
- 盈亏统计（总利润、胜率、最佳/最差交易）
- 支持手动添加、查看、撤销交易记录

### 14. 交易目标管理
- 设定交易目标（如"一周内赚 500p"）
- 追踪进度，目标完成后生成复盘报告

### 15. 事件驱动推送
- Prime Vault 回归 → 推送价格波动提醒
- Prime Access 上线 → 推送观望建议
- Baro 来访 → 推送购买推荐

## 交互方式

### 16. 飞书机器人
- WebSocket 长连接，无需公网 IP
- 支持文本消息和卡片消息
- 多轮对话上下文（"那犀牛呢"自动衔接上文）

### 17. Web 界面
- Tenno 科技终端风格 UI
- 实时聊天 + 价格图表
- 浏览器通知

### 18. 斜杠命令体系
- `/fav` — 关注物品管理
- `/scan` — 一键扫描关注物品
- `/alert` — 价格提醒管理
- `/fissure` — 裂缝订阅管理
- `/trade` — 交易记录管理
- `/relic` — 遗物查询
- `/strategy` — 交易策略扫描
- `/vault` — Vault 状态查询
- `/goal` — 交易目标管理
- `/pref` — 个人偏好设置

## 技术特点

- 数据源：warframe.market API + Warframe 官方 World State API
- **多模型协作架构**：
  - 本地模型：qwen3:8b（路由/ReAct）、warframe-agent（聊天）
  - 云端模型：kimi-k2.6（Mod 翻转预筛选）、glm-5.1（套装利润预筛选）、gpt-5.5（投资顾问预筛选）
  - 复杂度路由：简单查询走本地，复杂分析走云端
  - Scout 预筛选：云端 LLM 从 40+ 候选中选出 10 个最值得关注的，API 调用量减少 72%
- 缓存：内存 LRU + SQLite 持久化（订单 60s / 统计 300s / 持久化 10 分钟）
- 速率保护：线程安全速率限制器 + 随机抖动 + HTTP 429 自适应退避
- 并行化：Mod 翻转 8 线程、套装利润 6 线程并发扫描
- 推送渠道：飞书机器人 + WxPusher（微信推送）
- 支持平台：PC / PS4 / Xbox / Switch（跨平台交易）

## Agent 特性

- **记忆系统**：持久化用户偏好（交易风格/预算/风险偏好）、交易历史、关注列表
- **主动行为**：定时价格扫描、裂缝订阅推送、事件驱动通知（Baro/Vault/Prime Access）
- **学习能力**：记录交易结果，优化推荐策略，Scout 反馈闭环
- **个性化推荐**：基于用户历史和偏好定制投资建议

## 目标用户

Warframe 游戏内交易玩家，特别是：
- 需要快速查价格的活跃交易者
- 想找赚钱机会但不知从何入手的新手
- 需要批量分析套装/Mod 利润的商人
- 想追踪交易盈亏的投资者
