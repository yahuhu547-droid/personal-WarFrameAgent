# Warframe 交易助手 — 飞书机器人使用指南

> 适用于第一次使用飞书机器人的玩家。本机器人帮你查价格、找商机、做投资决策。

---

## 快速开始

### 1. 找到机器人

在飞书中搜索你的机器人名称，点击进入对话窗口。

### 2. 发第一条消息

直接输入物品名称即可查询价格：

```
充沛赋能
```

机器人会返回当前市场最低卖价、最高收价、价差，以及推荐的私聊命令。

### 3. 了解更多命令

```
/help
```

---

## 查价格（最常用）

直接用中文或英文输入物品名，机器人会自动识别并查询 warframe.market 实时数据。

| 你输入的 | 机器人返回 |
|----------|-----------|
| `充沛赋能` | 卖价 45p / 收价 35p / 价差 10p + 私聊命令 |
| `犀牛 Prime` | 整套 120p vs 拆件 95p，建议拆件买 |
| `川流不息` | 当前市场价格 |
| `arcane_energize` | 英文 ID 直接查询 |

**小技巧**：机器人会记住你最近问的物品，之后说"那犀牛呢"、"现在呢"会自动衔接上下文。

## 查套装差价

想知道一套 Prime 是整套买便宜还是拆件买便宜：

```
犀牛 Prime 一套多少钱
伏特 Prime 拆件买划算吗
```

机器人会对比整套价格和各部件价格之和，告诉你哪种方式更省钱。

## 补齐套装

如果你已经有了几个部件，想知道补齐还差多少钱：

```
补齐犀牛 Prime，我有蓝图和机体
```

机器人会算出你还缺哪些部件、每个多少钱、总共需要多少白金。

## 投资建议

有预算想找投资机会：

```
我有 500p 预算，有什么投资机会
投资推荐，ROI 至少 30%
```

机器人会按 ROI 排序推荐，过滤掉成交量太低的物品，并标注风险等级。

## 深度分析

对某个物品想做详细了解（使用云端大模型）：

```
深入分析充沛赋能
详细分析犀牛 Prime 的投资价值
```

返回 5 个维度的分析：价格评估、趋势判断、风险评估、投资建议、操作建议。

## 裂缝订阅（自动推送）

想在特定裂缝出现时收到通知？用 `/fissure` 订阅：

```
/fissure add 虚空 歼灭         订阅虚空星球的歼灭裂缝
/fissure add 后纪 钢铁         订阅后纪等级的钢铁裂缝
/fissure add 地球              订阅地球所有裂缝
/fissure add 古纪 防御 普通     订阅古纪防御普通裂缝
/fissure list                  查看当前订阅
/fissure remove 1              取消第1条订阅
```

当匹配的裂缝出现时，机器人会自动推送通知。

**支持的过滤条件：**
- 等级：古纪、前纪、中纪、后纪、遗珍、仲裁
- 任务：歼灭、捕获、防御、生存、救援、破坏、移动防御、间谍、拦截、挖掘
- 地点：虚空、地球、火星、金星、木星、塞德娜等
- 模式：钢铁、普通

## Baro 购买推荐

当虚空商人 Baro Ki'Teer 到来时，机器人会自动分析他的库存，推送购买建议：

- **值得买** — 市场价高于 Baro 杜卡特隐含价，从 Baro 买更划算
- **可考虑** — 非交易物品或无法获取市场价
- **不推荐** — 市场更便宜，建议从玩家手中购买

你也可以主动查询：
```
Baro 有什么值得买
Baro 推荐
```

## 遗物查询

想知道某个 Prime 部件从哪些遗物掉落：

```
/relic 犀牛 Prime 蓝图
/relic 充沛赋能
```

机器人会列出所有掉落该部件的遗物，以及每个遗物的掉落率。如果当前有匹配的裂缝，还会标注"现在可以刷"。

你也可以查询某个遗物的全部掉落物：

```
/relic Lith B1
/relic 前纪 B1
```

## 交易策略

预设策略帮你快速找到交易机会：

```
/strategy list          查看所有可用策略
/strategy run 低风险     扫描低风险赋能翻转机会
/strategy run 中风险     扫描中风险 Prime 拆件机会
```

- **低风险** — 高流动性赋能（R0 买 R5 卖），市场需求稳定
- **中风险** — 热门 Prime 套装拆件买卖
- **高风险** — Vault 投机囤货

## 斜杠命令

以 `/` 开头的命令可以管理机器人的记忆和设置。

### /help — 查看帮助

```
/help
```

### /fav — 关注物品

把经常查的物品加入关注列表，方便一键扫描：

```
/fav add 充沛赋能
/fav add 犀牛 Prime
/fav remove 充沛赋能
```

### /scan — 一键扫描

扫描所有关注物品的当前价格，以及是否触发了价格提醒：

```
/scan
```

### /alert — 价格提醒

设置价格阈值，当物品价格达到目标时提醒你：

```
/alert add 充沛赋能 below 45
/alert add 犀牛 Prime above 120
/alert remove 充沛赋能 below 45
```

- `below 45` — 当卖价低于 45p 时提醒（适合等降价买入）
- `above 120` — 当卖价高于 120p 时提醒（适合等涨价卖出）

### /goal — 交易目标

设定交易目标并追踪进度：

```
/goal                          查看当前目标
/goal set 一周内赚 500p          创建目标
/goal done abc123              标记完成
/goal drop abc123              放弃目标
/goal review                   复盘已完成的目标
/goal rm abc123                删除目标
```

复盘报告包含：交易次数、胜率、累计利润、最佳/最差交易。

### /pref — 个人偏好

```
/pref platform pc              设置平台（pc/ps4/xbox/switch）
/pref crossplay on             开启跨平台交易
/pref max 10                   每次查询最多显示 10 条结果
```

### /memory — 查看记忆

```
/memory
```

查看机器人记住你的所有信息：偏好、关注列表、价格提醒、查询习惯。

## 小贴士

1. **用中文就行** — 不需要记英文 ID，直接输入中文名（如"充沛"、"犀牛"）
2. **多轮对话** — 先问"充沛多少钱"，再说"那犀牛呢"，机器人会理解上下文
3. **价格都是白金** — 机器人说的价格单位都是游戏内白金，不是现实货币
4. **私聊命令可复制** — 机器人推荐交易时会附带 `/w` 私聊命令，直接复制粘贴到游戏内使用
5. **关注你的关注** — 把常查的物品加到 `/fav`，用 `/scan` 一键查看所有价格
6. **设提醒等低价** — 用 `/alert` 设置你想要的价格，降价了机器人会告诉你
7. **设定目标更有效** — 用 `/goal` 给自己定个交易目标，机器人会帮你追踪进度
