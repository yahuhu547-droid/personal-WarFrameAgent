## 二、严重问题（需立即处理）

### 问题 1: 欢迎模态弹窗阻挡所有操作 ⚠️

**问题描述**:
首次访问时，`welcome-modal` 弹窗完全覆盖页面，阻止用户与任何元素交互。

**根因分析**:
- 文件: `warframe_agent/web/static/index.html` 第 249-270 行
- 弹窗使用 `position: fixed` + `z-index` 覆盖整个视口
- 弹窗通过 `localStorage.getItem('warframe_visited')` 检测首次访问
- 检测到首次访问后自动显示弹窗，无关闭按钮或超时机制

**影响范围**:
- 首次访问用户体验差
- Playwright自动化测试无法正常执行（所有元素被弹窗阻挡）
- 用户必须完成平台选择才能使用应用

**关键代码片段**:
```html
<div id="welcome-modal" class="modal">
    <!-- 无"跳过"按钮，用户必须选择平台 -->
    <button id="start-btn" class="primary-btn">开始使用</button>
</div>
```

**建议修复方案**:
1. 添加"跳过"按钮，允许用户快速进入
2. 支持 ESC 键关闭弹窗
3. 添加 5-10 秒无操作自动关闭
4. 保存"不再显示"选项到 localStorage

---

### 问题 2: 缺失 favicon.ico 文件 ⚠️

**问题描述**:
HTML 引用 `/static/favicon.ico` 但文件不存在，导致 5 个 404 控制台错误。

**根因分析**:
- 文件: `warframe_agent/web/static/index.html` 第 30 行
- 引用: `<link rel="icon" type="image/x-icon" href="/static/favicon.ico">`
- 文件不存在于: `warframe_agent/web/static/` 目录

**影响**:
- 浏览器请求失败
- 控制台显示 5 个 404 错误
- 浏览器标签页无自定义图标

**建议修复方案**:
1. 创建占位 favicon.ico 文件
2. 或移除 HTML 中的引用
3. 或使用内联 SVG favicon

## 三、中等问题（建议优化）

### 问题 3: 移动端侧边栏宽度溢出

**问题描述**:
- 375px 视口下，侧边栏宽度 375px，可能溢出
- 截图: `md/test_screenshots/05_mobile_view.png`

**建议优化**:
1. 小屏幕下隐藏侧边栏，改为汉堡菜单
2. 使用 CSS `overflow-x: auto` 允许横向滚动
3. 添加滑动抽屉组件

2. Toast 提示网络错误
